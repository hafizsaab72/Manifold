The problem

Personalization at scale breaks inside the design tool

Personalization at scale is a real, daily need. A sales team wants a tailored one-pager for each open opportunity. A product team wants a fresh asset for every item in a catalog. A communications team wants the same announcement adapted for each region. The design is already approved. Only the content changes from one version to the next.

Express ships a native Bulk Create feature for exactly this kind of work, and its existence proves the need. But it was built as a light, one-time utility, and it stops well short of a production workflow.

  • It caps output at 99 variations.Real campaigns and catalogs routinely run well past that.
  • It accepts only a static CSV.There is no connection to the systems where the data actually lives.
  • It requires re-linking every element by hand each time the template is reopened.This is a limitation Adobe's own users have repeatedly raised.
  • It does not adapt copy that runs too long, and it does not enforce brand rules.Overflowing text breaks the layout, and nothing guarantees the output stays on-brand.

When the work outgrows that tool, teams fall back to two poor options. They duplicate slides manually, which is slow, error-prone, and drifts off-brand. Or they adopt heavyweight creative-automation platforms that live outside the design tool, carry enterprise pricing, and demand technical setup most teams do not have. Neither belongs in the hands of an individual creator or a lean marketing team, which is precisely who Express serves.

Approach

One approved design, a personalized set

Manifold is an Adobe Express add-on that turns one approved design into a personalized set: driven by data, governed by the brand, and repeatable on demand. The user opens Manifold inside Express on a design they have already approved as their master layout. From there, the workflow is six steps, and after the first run it is effectively three.

01
Connect
Link a data source: a Google Sheet, an uploaded CSV, or a live system such as a CRM or product catalog through a secure sign-in.
02
Map
Manifold reads the columns and proposes a mapping, suggesting which field fills which text layer and which image slot, so nothing is linked by hand.
03
Bind
The mapping is saved to the template. It persists, so the next run skips straight to generation.
04
Generate
Manifold produces one asset per record. Copy that runs long is fitted intelligently. Colors, fonts, and logos are held to the brand kit.
05
Review
The full set is presented for a quick pass, with anything that cannot comply clearly flagged.
06
Deliver
Export the set, or publish it. When the data changes, rerun or schedule a refresh, and the assets update without starting over.

Architecture

Built natively on the Adobe Express add-on platform

Manifold runs inside Express under the same security model as any approved add-on. Each capability below maps to a documented, supported part of the Adobe Express add-on SDK.

Secure connections

The Add-on UI SDK OAuth APIs authorize access to third-party systems using the standard PKCE flow, with tokens persisted so users do not sign in every session.

Live data

The iframe runtime fetches and shapes data from connected sources, then passes it to the document environment through the SDK communication APIs.

Native generation

The Document APIs create pages and place content programmatically inside the user's document, so output is real, editable Express content rather than flattened images.

Persistent bindings

Mappings are stored through client storage and a lightweight backend, which removes the repeated re-linking that limits the native tool.

The intelligence layer

A model does the work that makes the difference between a swap tool and a production engine. It suggests field-to-element mappings so setup is a confirmation rather than a chore. It fits overflowing copy while preserving meaning, instead of breaking the layout. It drafts optional tailored copy per record or segment. And it checks each asset against brand rules, flagging or correcting what falls outside them.

Who it is for

Manifold serves the teams who hit the wall the moment one design needs to become many. Four patterns recur.

Sales and enablement

Generate a tailored one-pager or leave-behind for every open opportunity, pulling account name, industry, and the right proof points straight from the CRM.

Product marketing

Produce a fresh, on-brand asset for every item in a catalog or price list, and refresh the entire set the moment the source updates.

Regional and localized campaigns

Adapt one approved announcement across markets and segments, holding the brand steady while the content changes.

Recurring communications

Turn a master template into a repeatable run for newsletters, reports, and internal updates, without rebuilding the link each cycle.

Pricing

A freemium model that proves itself first

Manifold is freemium, the model Adobe notes performs best, and it is designed so the value is felt on a real workflow before anything is paid for. The free tier is enough to run a genuine job end to end. The paid tier unlocks the connections, scale, and automation that teams reach for once Manifold becomes part of how they work.
